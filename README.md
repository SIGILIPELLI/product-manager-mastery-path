# Product Manager Mastery Path

A free, structured, module-wise product management training program — entry
level to master level, with real frameworks and templates in every module and
a hands-on deliverable at the end of each level.

**Live site:** https://sigilipelli.github.io/product-manager-mastery-path/

## Contents

- **Level 1 · Entry** — core PM fundamentals: discovery, prioritization, requirements, metrics, roadmaps
- **Level 2 · Intermediate** — experimentation, analytics, go-to-market, pricing
- **Level 3 · Advanced** — strategy, OKRs, platform thinking, growth
- **Level 4 · Master** — leading product orgs, portfolio strategy, executive communication

## Local development

```bash
python3 -m venv .venv
.venv/bin/pip install mkdocs-material
.venv/bin/python -m mkdocs serve
```
